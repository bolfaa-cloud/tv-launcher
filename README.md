# Анис ТВ

Лаунчер для Android TV в стиле Apple TV: приветствие, крупные часы, дата и погода, стеклянный док с приложениями.

Свежий APK: раздел **Releases** → `AnisTV.apk`. Собирается автоматически GitHub Actions при каждом изменении.

## Основа

Сделан на основе лаунчера из [CleanYourTV](https://github.com/Gathin23/cleanyourtv) (Gathin, лицензия MIT, см. `LICENSE`).
Изменения: название «Анис ТВ», своя иконка и баннер, отдельный идентификатор приложения `com.bolfaa.anistv`.
